# Phishing URL Detector

A simple Python project for checking URLs for common signs of phishing.

## About the Project

I made this project to learn some basic cybersecurity concepts using Python.

The program checks a URL and looks for a few patterns that may indicate a suspicious link.

## Features

- Check URLs for suspicious patterns
- Detect IP addresses in URLs
- Check for unusual characters
- Look for common phishing indicators
- Show a simple result
- Easy command-line interface

## Technologies Used

- Python 3
- Regular Expressions
